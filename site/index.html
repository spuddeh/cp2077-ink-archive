What this is

Every ink (UI) resource in Cyberpunk 2077 - 3,915 files, 1,081,184 chunks - as a queryable database. Widget trees, animations, atlases, styles, fonts, layer definitions, credits and character-customization data, base game and Phantom Liberty, game version 2.31.

The page queries a SQLite database over HTTP range requests; only the pages a query touches are downloaded. The archive itself, the extraction scripts and the verification that nothing was lost are in the repository this site is published from.
