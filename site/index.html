Scroll to zoom, drag to pan, double-click to reset. A click selects the smallest box under the cursor; click the same spot again for the box behind it.

The archive as folders, files, and every handle and resource path a record holds, opened one node at a time. Widget children come first, in the order the engine walks them; the other fields of a chunk follow by name, then the resources it names. A resource that is an archive file opens in place. focus re-roots the tree on a node and opens the path down to it from the top; a file's referenced by lists the records in other files that name it.

What this is

Every ink (UI) resource in Cyberpunk 2077 - 3,915 files, 1,081,184 chunks - as a queryable database. Widget trees, animations, atlases, styles, fonts, layer definitions, credits and character-customization data, base game and Phantom Liberty, game version 2.31.

The page queries a SQLite database over HTTP range requests; only the pages a query touches are downloaded. The archive itself, the extraction scripts and the verification that nothing was lost are in the repository this site is published from.
